# Code of Conduct

Мы хотим, чтобы в AvtoBus было комфортно работать всем.

## Стандарт

- Уважительное общение, конструктивная критика кода, а не людей.
- Терпимость к вопросам новичков; EDA — сложная тема.
- Никаких оскорблений, харассмента и троллинга — в issue, PR, обсуждениях и чатах.

## Неприемлемо

- Оскорбления и уничижительные комментарии.
- Публикация чужих персональных данных.
- Сознательный саботаж ревью (затягивание без аргументов, dismiss без причины).

## Enforcement

Нарушения — приватным письмом мейнтейнерам (см. `SECURITY.md` для контактов
приватной связи). Меры: предупреждение, временный или постоянный бан —
по тяжести и повторности.
